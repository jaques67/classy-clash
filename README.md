# Dapper Dasher

Classy Clash is a C++ game made with Raylib as taught by GameDev.TV and is the third game in the [C++ Fundamentals: Learn Game Programming For Beginners](https://www.gamedev.tv/courses/cpp-fundamentals/top-down-game-setup/1986) course.
This is a top down game

Teaches:
* Creating a map
* Vectors
* Classes, Getters and Setters
* Scope
* Header Files and Constructors
* Constructor Arguments
* Class Inheritance
* Overriding functions
